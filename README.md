# docs-assistant
社内資料をもとにAIが回答するナレッジQAアプリ
## 1.誰が使うのか
- 社長・社員・総務など、全社共通の資料を登録する人・アカウントを管理する人（情シス担当など）
## 2. その人は、いまどんなことに困っているのか
- 社員：どこに何が書いてあるか分からない。詳しい人に聞くしかない。
- 社長：何がわからなくて詰まっているのか、見えない
## 3. このアプリで何ができるようになるのか
- 社内資料をアップロードし、社員はチャット形式で必要な疑問を解消することができる。また、社長は社員のチャットログを閲覧することができる。
- 社員ごとに閲覧・回答を得る資料を制限することができるので、役職ごとに得られる情報を分けることができる
## 4. 使う人の種類（ロール）と、それぞれができること
- **ceo（社長）**
  - 全資料の閲覧・登録・削除
  - 全社員のチャットログ閲覧
  - 社員データ閲覧
  - チャット
- **source_manager（共通ソース管理者）**
  - 全社共通の資料登録・削除のみ
  - 個別資料には触れない
  - スタッフ一覧も見られない
- **employee** 
  - 共通資料に質問するだけ
- **admin（システム管理者）**
  - アカウントの作成・ロール変更・パスワード上書きのみ
  - 資料もログも中身は一切見られない
- ※1人1ロール。兼任はできない
## 5.最初のバージョンで作るもの/作らないもの
判断の基準
- 無いと成立しない → 最初に作る
- 人の手で代われる → 後回し
### 最初に作る
- ログイン・ロール判定
- チャット
- 共通資料と個別資料の出し分け（データの持ち方として）
### 後回し
- 資料のアップロード（手で置けばいい）
- 資料の一覧・削除画面（同上）
- スタッフ一覧・社員データ画面
- チャットログ閲覧
- アカウント管理画面（CSVやDBを直接いじればいい）
- パスワード変更
